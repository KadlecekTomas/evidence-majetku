# Evidence majetku

Moderní evidence školního majetku navržená pro rychlou práci s QR kódy, místnostmi, inventurami, závadami a servisní historií. GORDIC zůstává účetním systémem a tato aplikace tvoří jednoduchou provozní vrstvu s řízenou synchronizací.

> Projekt je ve fázi počátečního vývoje. Produkční architektura a integrační kontrakty jsou připravovány GORDIC-ready od prvního commitu.
